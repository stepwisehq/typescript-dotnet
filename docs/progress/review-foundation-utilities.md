Initial length now controls unchanged, replacement/deletion, and residual-copy arms. - **Fixed:** required ParameterList/Parameters accessors and exact Node.Text kind cases had permissive null/broad-literal behavior. Original Go invalid-accessor probes pass on Release9.
- **Reviewed:** pragma-map absent reads use null/missing-key behavior; generated predicates retain their literal Kind ranges; no unsupported/no-op body was found in the reviewed pure syntax families.
