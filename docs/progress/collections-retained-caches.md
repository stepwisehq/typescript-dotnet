string mappings, instantiation-expression syntax if admission rejects it, module

assertion or source-call disposition in the final observer. They must not be declared
impossible simply because no current fixture uses them. This ledger does not silently
expand user syntax to trigger those producers.

A pending disposition is not automatically a demand for new serialization. Unchanged
literal/merge/error/formatter families can rely on the stated accepted association,
identity/output/order evidence and reviewed source producers; their omitted global or
emitted-node census is explicit. New/changed generic, tuple/signature, indexed/conditional/
mapped/reverse, relation and flow/iteration key families require concrete closure.
