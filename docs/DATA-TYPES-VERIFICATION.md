The stored richer corpus has 14 tiny and 78 matrix cases. A separate 14-case base-only integration corpus is triage evidence and excluded from richer acceptance counts. [The manifest](../validation/data-types-corpus/manifest.json) maps every named case to its contract group; [the coverage inventory](../validation/data-types-corpus/coverage.json) measures actual edges/fields rather than inferring branches from source syntax.

Original Go reflection independently flattens every reachable nonleaf payload field; unknown fields/types fail. The static managed observer lists typed fields manually and uses source-generated JSON for Native AOT. The base graph remains authoritative for intrinsic/literal flags/values/fresh-regular identities. Type wrapper IDs/data/checker backreferences are excluded from recursive serialization. Alias, mapper, index, table, symbol and type identities are registered before following edges. Nullable model fields/tables/maps retain null versus allocated-empty identity; semantic list order, diagnostic order and cycles are preserved. Existing top-level diagnostic channels normalize nil slices to empty arrays, while individual diagnostic argsNull/raw arguments are retained.

Observation order is explicit in the manifest: original parser graph, diagnostics, queries/formatting, directed relationships, globals, repeated declared types, repeated widening, node caches, indexed type/property/payload/existing-propertiesTypes-cache queue and symbol-link queue to closure, final type flags, then actual key lookups. Fields snapshot storage at their queue visit; absent caches are not forced. The queues add identities by index and do not enumerate a live growing collection.

All logical node/type-node cache presence and contents are compared, as are value/type-alias/declared/deferred/mapped/reference/module/merged symbol links. Actual per-node resolved symbols are compared. Existing propertiesTypes entries are read for each queued type, preserving exact include/includeOrigin keys and canonical value identities; map presence is retained and absent entries are not populated. Physical presence of an untouched zero slot in paged symbolNodeLinks is excluded because process-global AST IDs affect page placement; the earlier 20 fixed-ID utility observations remain the exact storage-layout regression.

Opaque Go XXH3 bits differ deliberately from the managed complete-preimage key representation. The graph retains map presence/cardinality/canonical value identities; populated interface instantiation entries additionally execute actual key-to-same-instance lookups. Union/intersection records execute actual intern-cache lookups. Key probes compare type-list/alias/union/intersection/instantiation preimages and actual constrained hidden-this reference normalization, including ignoreConstraints/state differences. Cache-only types use a unique stable descriptor to seed identities; collisions fail rather than merge entities. Associations outside the observed populated key families remain unverified.
